## 주요 분석 결과

1. **결측 구조:** 연료원별 사용·화학반응공정 158건은 탄소발자국만 제공됩니다. 오존층영향은 원료 단계 결측률 93%로 분석에서 제외했고, 광화학스모그(보유율 78%)는 선택적으로 사용합니다.
2. **선별 편향:** 5개 범주가 모두 유효한 142/187건만 군집화 대상이며, 에너지(78%)·건축자재(57%)의 제외 비율이 높습니다. 화면에서 범주를 바꿀 때마다 제외 비율을 즉시 표시합니다.
3. **탄소발자국의 대리성 한계:** 탄소–자원 ρ 0.74, 탄소–산성화 0.81, 탄소–부영양화 0.70, 그러나 탄소–물소모는 0.32. 탄소 백분위보다 타 범주 백분위가 40%p 이상 높은 원료가 25종(골판지·트랜지스터·유리면 등).
4. **단계별 격차:** 수송은 항공/외항선 탄소 계수가 약 490배, 폐기는 소각/재활용 중앙값이 약 52배 차이(재활용 회피 부하 반영 여부는 원자료에서 확인 불가).
5. **군집 구조는 탐색적:** 사전 규칙(안정성 ≥0.95, 최소 군집 ≥10%, Davies–Bouldin 최소)으로 k=3 선택. 실루엣 0.33(경계 모호), 범주 구성을 바꾸면 ARI 0.55~0.69.

## 화면 구성

- **분석 리포트:** 핵심 지표 → 결측 구조·선별 흐름도 → 범주 간 상관(축 선택형 산점도) → 수송·폐기 단계 비교(범주 선택) → 군집 구조·타당성 → 해석 범위 → 방법·용어.
- **환경영향 계산:** 단계→대분류→항목 선택 + 검색. **항목 추가 후에도 선택 상태 유지**, 동일 항목 수량 합산, 목록 localStorage 저장, 기여도(hotspot) 분석, 대체 원료 Δ% 검토, 기준안 대비 비교, CSV 저장. 결과 규모를 **승용차 주행거리·전력 사용량·소나무 연간 흡수량·생수병 수·1인 일일 상수 사용량**으로 환산합니다. 결측은 0으로 대체하지 않고 ‘부분합계’로 표기.
- **데이터 분석:** 순위·분포·박스·산점도·상관행렬·레이더 프로파일, 구분 필터.
- **군집 분석:** 사용 범주와 k를 직접 선택해 실루엣·안정성·군집별 중앙값 배수를 확인, 항목 조회, Python(scikit-learn) 결과와의 일치도 표시(기본 설정에서 142/142, ARI 1.00).

## 생활 환산 기준 (확인 필요)

| 전력 사용량 | 0.4173 kgCO₂eq/kWh | 2023 국가 전력배출계수(온실가스종합정보센터·한국에너지공단) |
