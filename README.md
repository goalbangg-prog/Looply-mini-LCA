## 주요 분석 결과

1. **결측 구조:** 연료원별 사용·화학반응공정 158건은 탄소발자국만 제공됩니다. 오존층영향은 원료 단계 결측률 93%로 분석에서 제외했고, 광화학스모그(보유율 78%)는 선택적으로 사용합니다.
2. **선별 편향:** 5개 범주가 모두 유효한 142/187건만 군집화 대상이며, 에너지(78%)·건축자재(57%)의 제외 비율이 높습니다. 화면에서 범주를 바꿀 때마다 제외 비율을 즉시 표시합니다.
3. **탄소발자국의 대리성 한계:** 탄소–자원 ρ 0.74, 탄소–산성화 0.81, 탄소–부영양화 0.70, 그러나 탄소–물소모는 0.32. 탄소 백분위보다 타 범주 백분위가 40%p 이상 높은 원료가 25종(골판지·트랜지스터·유리면 등).
4. **단계별 격차:** 수송은 항공/외항선 탄소 계수가 약 490배, 폐기는 소각/재활용 중앙값이 약 52배 차이(재활용 회피 부하 반영 여부는 원자료에서 확인 불가).
5. **군집 구조는 탐색적:** 사전 규칙(안정성 ≥0.95, 최소 군집 ≥10%, Davies–Bouldin 최소)으로 k=3 선택. 실루엣 0.33(경계 모호), 범주 구성을 바꾸면 ARI 0.55~0.69.

## 화면 구성

- **분석 리포트:** 핵심 지표 → 결측 구조·선별 흐름도 → 범주 간 상관(축 선택형 산점도) → 수송·폐기 단계 비교 → 군집 구조 → 해석 범위.
- **환경영향 계산:** 단계→구분→항목 선택과 검색. **항목을 추가해도 선택이 유지**되고, 같은 항목은 수량이 합산되며 목록은 새로고침 후에도 남습니다. 기여도(hotspot), 대체 원료 Δ% 검토, 기준안 비교, CSV 저장을 지원합니다. 결과는 승용차 주행거리·전기 사용량·소나무 흡수량·생수병 수·1인 일일 물 사용량으로 환산해 보여 주며, 결측은 0으로 넣지 않고 ‘5건 중 4건 반영’처럼 표기합니다.
- **데이터 분석:** 순위·히스토그램·박스플롯·산점도·상관행렬·레이더 차트, 구분 필터. 레이더는 구분별 드롭다운에서 항목을 언제든 바꿀 수 있습니다.
- **군집 분석:** 사용 범주와 k를 직접 바꿔 실루엣·안정성·군집별 중앙값 배수를 확인하고 항목을 조회합니다(기본 설정에서 Python 결과와 142/142 일치).
- **방법·출처:** 통계 용어를 ‘전문 용어(쉬운 풀이)’ 형식으로 설명하고, 환산 기준 출처·기술 스택·한계·코드 링크를 모았습니다.
- 화면 전환·스크롤 등장·막대 차트에 부드러운 애니메이션을 적용했으며, OS의 ‘동작 줄이기’ 설정을 존중합니다.

## 한계와 향후 과제

- 원자료에 **불확도·산출 근거가 없고**, 2021년 기준이므로 현재 전력믹스·공정과 다를 수 있음.
- 합계는 선택 항목의 단순 곱셈·합산이며 시스템 경계·기능단위·할당이 없는 **부분 산정**.
- Plotly 차트의 실제 렌더링은 샌드박스에서 시각 확인하지 못함(상호작용·데이터 흐름은 스텁으로 검증). 배포 후 실제 브라우저 확인 필요.
- 원자료 이용·재배포 조건 확인 필요.
- 향후: 불확도 입력(몬테카를로), 영향범주 가중치 시나리오, 단위 변환 지원, 접근성 점검.
