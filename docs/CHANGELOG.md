# 변경 이력

## v7 (가독성·버그 수정)
- 문구를 ‘전문 용어(쉬운 풀이)’ 형식으로 재구성, ‘보유율’을 ‘값이 있는 비율’로 변경.
- 버그: 레이더/군집 조회의 입력창(datalist)을 드롭다운으로 교체해 재선택 가능, 같은 축 선택 시 안내 문구가 차트와 겹치던 문제 수정, 계산기 우측 영역이 가로로 넘치던 문제 수정.
- 결과 카드의 단위 표기를 분리하고 ‘5건 중 4건 반영’만 표시.
- ‘방법·출처’ 탭 신설(용어 풀이, 환산 기준 출처, 기술 스택, 한계). 계산기에서는 출처 문구 제거.
- 환산 기준 갱신: 물 사용량 305.9 L(2024), 소나무 6.6 kg(30년생); 전력 0.4173(2023 최신), 승용차 125.2 g/km(확인된 최신 공식 실적).
- 줄바꿈·정렬 정리, 화면 전환/스크롤 등장/막대/호버 애니메이션 추가(동작 줄이기 설정 존중).
- tests/e2e_smoke.py 추가.
