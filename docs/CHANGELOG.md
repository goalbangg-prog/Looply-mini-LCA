# Looply 개발·수정 이력

이 문서는 저장소의 기능 발전과 사용자 피드백에 따른 수정 사항을 주제별로 정리한 기록입니다. 버전은 개발 중 사용된 작업 구분이며, 모두 독립적으로 검증 완료된 릴리스를 의미하지 않습니다.

## 2026-10-16 — 계산기 개선과 Python 검증 (GitHub Pages 단독 배포)

### 변경
- **단위 변환기 삭제:** 별도 변환기 화면과 관련 코드를 제거. (계산 목록의 항목별 입력 단위 선택, 예: kg → t은 유지)
- **계산 목록 이름 수정:** `가정`처럼 사용처만 보이던 항목을 `경유 · 가정`(구분 · 사용처)으로 표시. 계산 목록, 결과표, 기여량 그래프, 탐색·군집 목록에 같은 규칙 적용
- **선택 3단계 단순화:** 대분류 → 구분 → 소분류. 기존 '이름으로 좁히기' 드롭다운은 **이름 검색창**으로 교체(검색하면 구분·소분류 목록이 함께 줄어듦)
- **PC 전용:** 모바일·좁은 화면용 CSS를 모두 삭제하고 최소 너비 1180px 기준으로 정리
- **보고용 군집 수 3개 선정:** 리포트·군집 탭에 선정 이유 명시, 군집 탭 기본값 4→3. '군집 수 추천' 버튼은 자동 선택 대신 군집 수별 점수 표시로 변경
- **JavaScript KMeans 개선:** 초기 중심 선택을 k-means++(고정 시드)와 10회 시도로 변경해 scikit-learn 방식에 가깝게 조정
- **리포트 군집 번호:** 중심값 평균이 낮은 순서로 번호를 붙여 군집 탭과 일치
- **배포 정리:** Python 앱 프로토타입(`python/`)과 GitHub Pages 외 배포 관련 파일·문구를 모두 삭제. 배포는 GitHub Pages만 사용

### 추가
- `notebooks/kmeans_silhouette_sklearn.ipynb`: scikit-learn으로 k=2~6 비교(실루엣·Davies-Bouldin·관성·시드 안정성), k=3 해석, 웹앱 결과와 비교
- `data/sklearn_kmeans_k3.csv`, `data/web_kmeans_k3.csv`: 비교에 사용한 군집 결과

- 기존 가로 탭을 **좌측 고정형 메뉴**로 전환

- 비교 가능한 데이터가 존재하는 영향항목 조합만 산점도에 제시하도록 로직 조정

- 산점도 외 모드에서 보조 영향 항목의 비활성화 처리
- **주의:** 전체 조합 자동 테스트 및 브라우저 회귀 검증은 별도 필요
