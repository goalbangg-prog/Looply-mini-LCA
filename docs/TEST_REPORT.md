## 한 검증
- 헤드리스 크롬(Playwright, 화면 너비 1180·1280)에서 네 화면을 모두 열고 계산·탐색(5개 방법 × 5개 범위)·묶어 보기(k=2~6, 영향 선택 변경, 값이 부족한 범위)를 조작: **JavaScript 오류 0건**, 가로 스크롤 없음(너비 1180)
- **계산 검산:** 시멘트 1,000 kg + 알루미늄 판 200 kg + 고밀도 폴리에틸렌 50 kg + 생활폐기물 매립 100 kg + 육상수송 BCT 5 ton.km의 영향 7종 합계가 pandas로 직접 계산한 값과 일치(탄소 1,464.65). 시멘트를 1 ton으로 바꿔도 1,000 kg과 같은 결과
- **빈 값 처리:** 값이 없는 영향은 "자료 없음"으로 표시, 합계에는 "5건 중 n건만 반영"으로 표시, 0으로 대체하지 않음. CSV 저장 파일 내용 확인(합계 행·반영 건수 행 포함)
- **Python과 웹 숫자 비교:** 영향 쌍 15개의 순위 상관과 비교한 개수 n이 SciPy 결과와 같음(소수 둘째 자리 반올림 차이 ≤ 0.005). "탄소 순위보다 다른 영향 순위가 40점 이상 높은 원료" 25개도 두 쪽이 같음
- **군집:** 기본 설정(5개 영향, k=3)에서 웹(JavaScript)과 scikit-learn(1.9.1) 결과가 142개 모두 같음(ARI 1.00). k=2는 크기·실루엣(0.329)이 같고, k=4~6은 무리 크기가 같거나 거의 같지만 실루엣은 k=5에서 0.307 대 0.309, k=6에서 0.316 대 0.315로 조금 다름
- 노트북 `reanalysis_sklearn.ipynb` 전체 실행, 결과 저장
