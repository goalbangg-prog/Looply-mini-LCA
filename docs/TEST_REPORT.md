# 검증 기록

2026-10-16 수정본(`index.html` 현재 버전) 기준으로 **실제로 수행한 검증**과 **수행하지 않은 검증**을 구분해 적었습니다.

## 수행한 검증
- 데스크톱 크롬(헤드리스, Playwright)에서 `index.html`을 열어 네 화면과 데이터 인사이트 5개 분석 방법·5개 대분류를 모두 조작: **JavaScript 오류 0건**
- 계산 검산: 1종 포틀랜드 시멘트 500 kg + 강화유리 20 kg + 경유(가정) 10 L → 탄소발자국 510.19 kg CO₂ eq (직접 계산과 일치). 시멘트 입력 단위를 kg → t로 바꾸면 해당 항목이 1,000배로 반영됨
- 선택 3단계(대분류 → 구분 → 소분류)와 이름 검색(검색 결과가 있을 때 / 없을 때) 동작 확인
- 계산 목록에서 `경유 · 가정`처럼 구분과 함께 표시되는 것 확인
- Python(scikit-learn 1.9.1)과 웹(JavaScript) KMeans 비교: k=3, 142개 항목 **142개 모두 같은 군집**(ARI 1.0)
- 노트북 `kmeans_silhouette_sklearn.ipynb` 전체 실행 및 결과 저장

## 수행하지 않은 검증 (한계)

- GitHub Pages 실제 배포 주소에서의 동작
- 모든 입력 단위 조합, CSV 내려받기 파일 내용의 독립 검산
